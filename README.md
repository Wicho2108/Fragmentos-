# Fragmentos-
Utiliza de referencia los dos proyectos compartidos en la carpeta de recursos (Lista.zip, Fragmentos.zip) y crea un programa nuevo que apartir de un listview carge y remplaze respectivamente los fragmentos. Es decir si yo seleccion un gato, en la parte de abajo se reemplaza con el fragment que trae la imagene del gato y la descripción.
